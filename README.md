# DZEN Frame Bot

Telegram-бот компании DZEN, разработанный для премии «Новые люди».

Пользователь может загрузить фотографию или выбрать фото из своего профиля Telegram. Бот автоматически находит лицо, кадрирует изображение и накладывает фирменную рамку премии, после чего отправляет готовый результат.

Фотографии обрабатываются без постоянного хранения на стороне приложения.
