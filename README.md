# DZEN Frame Bot

Telegram-бот для участников премии Дзена «Люди слова».

Пользователь загружает одну фотографию или выбирает доступную фотографию
профиля Telegram. Бот находит лицо, кадрирует изображение без полей, накладывает
фирменную рамку и возвращает результат как превью и как файл без дополнительного
сжатия.

## Основные требования

- одна фотография на одну обработку;
- кадрирование по лицу, а при его отсутствии — по центру;
- квадратный результат размером 1280×1280 без полей;
- получение фотографии из сообщения или профиля Telegram;
- обработка изображений в оперативной памяти без постоянного хранения;
- обезличенная статистика без фотографий и Telegram `file_id`;
- локальный запуск через long polling.

## Технический стек

- Python 3.12;
- aiogram 3;
- MediaPipe Face Detector;
- Pillow;
- SQLite;
- pytest.

Секреты и пользовательские фотографии не должны попадать в Git, базу данных или
логи приложения.

## Обработка изображений

Поиск лица выполняется локально моделью MediaPipe BlazeFace без внешнего API.
Основное лицо размещается выше и правее центра, чтобы фирменная надпись не
закрывала его. Если лицо не обнаружено, используется центральное кадрирование.
Поля не добавляются: фотография всегда обрезается до квадрата и масштабируется
до 1280×1280.

Исходная фотография и оба результата представлены в приложении только как байты
в оперативной памяти. Модуль обработки не записывает пользовательские изображения
на диск.

## Локальная разработка

Проект использует Python 3.12 и менеджер окружения `uv`. На macOS `uv` можно
установить через Homebrew:

```bash
brew install uv
```

Создание управляемого Python и установка проекта:

```bash
uv python install 3.12
uv sync --extra dev
cp .env.example .env
```

После этого в `.env` нужно указать токен, полученный у BotFather. Сам файл `.env`
игнорируется Git и не должен публиковаться.

Запуск локального long polling:

```bash
uv run python -m dzen_frame_bot
```

Проверки перед передачей изменений:

```bash
uv run ruff check .
uv run pytest
```
